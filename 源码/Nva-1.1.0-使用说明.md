# TQ 1.1.0 使用说明

1. 保持 `Nva本地离线解析.exe`、`NvaAssets.pak`、`models`、`WinDivert.dll` 和 `WinDivert64.sys` 在同一个程序目录。
2. 以管理员身份双击 `Nva本地离线解析.exe`。
3. 输入当前热点设备编号，或直接输入设备 IPv4；选择后立即开始实时解析。
4. CMD 中 `W` 打开网页，`D` 查看详情，`S` 停止并重新选择设备，`Q` 保存并退出。

`NvaParser.exe` 已内置，无需单独保留 `parser` 文件夹。资源包由程序直接读取，不会释放出头像、物资或 2D 地图图片。3D 地图固定从主目录下的相对路径 `models` 读取。

网页的“3D 场景”页可选择人物模型、朝向箭头/直线、朝向头部/脚底，以及可见和掩体后颜色。浏览器仍显示旧样式时按 `Ctrl+F5`。
